# Ekilia — Paleta

En web se usan los tonos **Noche** (más profundos) más el azul de confianza. Los swatches claros del cuadro brillan demasiado como campo.

| Color | Rol | HEX | RGB | HSL |
| --- | --- | --- | --- | --- |
| Azul | Confianza (primario) | `#0E6E9E` | `rgb(14, 110, 158)` | `hsl(200, 84%, 34%)` |
| Hueso | Claridad (fondo) | `#F6F3EE` | `rgb(246, 243, 238)` | `hsl(38, 31%, 95%)` |
| Turquesa | Naturaleza (complemento) | `#0F6468` | `rgb(15, 100, 104)` | `hsl(183, 75%, 23%)` |
| Mora | Innovación / equilibrio | `#3E2770` | `rgb(62, 39, 112)` | `hsl(259, 48%, 30%)` |

Tinta de lectura: `#1A1228`.

---

## Cómo se usa

| Color | CSS | Superficie |
| --- | --- | --- |
| Hueso | `--cream` | Fondo, wordmark, riel |
| Azul | `--forest` | Menú, Centia — confianza primero |
| Turquesa | `--band` / `--turquoise` | Franja de reposición, flora, bloom |
| Mora | `--petroleum` | Nervia — innovación después |

Apoyos: hueso profundo `#E6DFD4`; turquesa profundo `#0B4C50`; mora profunda `#2A1B4D`.
